# CAI_ARCHIVE — personal portfolio

A responsive retro-archive portfolio built with plain HTML, CSS, and JavaScript. No build tools or paid services required.

## Preview locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Sign in to GitHub and create a new **public** repository (for example `portfolio`).
2. Upload `index.html`, `styles.css`, and `script.js` from this folder to the repository root.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch `main`, folder `/ (root)`, then Save.
6. Wait a few minutes. GitHub will show the published URL in Settings → Pages.

## Personalize before sharing
- Replace the LinkedIn URL in `index.html` with your actual profile URL.
- Add an email address or remove the email placeholder.
- Replace the CSS-generated project cover art with your own screenshots when ready.
- Review project descriptions and update roles, collaborators, dates, and outcomes so every claim is accurate.

## Edit project content
Project cards are in `index.html` under `#work`. Project detail sections are under `#projectDetails`.
To add a real image, put it in `assets/` and use e.g. `<img src="assets/moi-screenshot.png" alt="Moi game interface">`; style it in `styles.css`.
